# Hardware Engineer

**Lucid Computing**

**Areas & skills:** AI safety & policy

## Summary
- In this role, you'll design verifiable computation pipelines for GPU workloads, proving kernel execution integrity against model specifications.
- Build low-level software in C, C++, or Rust interfacing with TEEs and cryptographic accelerators to attest computation integrity.
- Implement static kernel analysis tools extracting memory patterns and computational structure from GPU kernels (Triton, CUTLASS, PTX/SASS).
- Liaise with silicon vendors (NVIDIA, AMD, Intel) on security architectures, side-channel implications, and accelerator roadmaps.
