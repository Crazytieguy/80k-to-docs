# Computational Biologist

**[Claryx](https://www.claryx.com/)**

- **Location:** New York, NY, USA
- **Role type:** Full-time
- **Experience:** Junior (1-4 years experience), Mid (5-9 years experience)
- **Degree:** Undergraduate degree or less
- **Salary:** $90,000 – $110,000

## Tags
Biosecurity & pandemic preparedness, Software engineering

## Summary
- In this role, you'll build and maintain bioinformatics pipelines and data infrastructure for a hospital pathogen biosurveillance platform.
- Design metagenomic analysis workflows for taxonomic profiling and antimicrobial resistance detection.
- Build predictive models from genomic data and create dashboards for communicating results.
- Deploy containerized workflows on AWS using workflow managers to ensure reproducibility.
- Implement HIPAA/SOC 2 compliant security protocols including audit logging and encryption.
